# 📚 Wordly Dictionary SPA

A simple, responsive Single Page Application (SPA) that allows users to search English words and instantly get meanings, examples, synonyms, antonyms, phonetics, and pronunciation audio using a free Dictionary API.

---

## 🚀 Features

- 🔎 Search any English word
- 📖 Displays:
  - Word meaning
  - Part of speech (type)
  - Example sentence
  - Synonyms & antonyms
  - Phonetic spelling
- 🔊 Audio pronunciation playback
- ⭐ Save favorite words (LocalStorage)
- 🗑️ Remove saved words
- 🔁 Click saved words to re-search them
- ⚡ Real-time API integration
- 🧠 Error handling for invalid words
- 📱 Clean and responsive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Dictionary API

## ⚙️ How It Works

1. User enters a word in the search bar  
2. JavaScript sends a request to the Dictionary API  
3. API returns word data (meaning, phonetics, etc.)  
4. Data is dynamically displayed in the UI  
5. User can:
   - Play pronunciation audio 🔊  
   - Save words to favorites ⭐  
   - Click favorites to search again 🔁
