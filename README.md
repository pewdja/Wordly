# Wordly

Search for any English word
See the meaning and word type (noun, verb, etc.)
View example sentences
Find synonyms and antonyms
Listen to how the word is pronounced
Save favorite words
Remove saved words
Works well on both desktop and mobile
Built with
HTML
CSS
JavaScript
Free Dictionary API
How it works
Type a word into the search box
The app gets data from a dictionary API
It shows the meaning, examples, and more
You can save words you like for later
API used

Uses the free Dictionary API:
